# Compounding invasion risk: mapping global co-occurrence of freshwater invaders

A global, spatially-explicit test of the invasional-meltdown hypothesis
across 11 freshwater invasive species (fish, crayfish, bivalves), using
species distribution models fit to river-network-aware environmental data
(HydroATLAS + FutureStreams), validated against real co-occurrence records
and cross-referenced against freshwater biodiversity value.

See [`research_proposal.md`](research_proposal.md) for the full background,
research questions, methods rationale, timeline, and open risks.

This project follows the
[Open Research Workflow](https://olivierraven.github.io/Open_Research_Workflow/):
`analysis.qmd` holds every computation, `index.qmd` is the manuscript that
only reads precomputed outputs, and the two are kept in sync on every commit.

## Reproducing this project

1. Install [Quarto](https://quarto.org) and R (≥ 4.3 recommended).
2. Restore the package environment:
   ```r
   install.packages("renv")
   renv::restore()
   ```
3. Render the analysis first, then the manuscript:
   ```bash
   quarto render analysis.qmd
   quarto render index.qmd
   ```
   Or render everything: `quarto render`.

## File structure

```
.
├── _quarto.yml           # project + citation-style config
├── index.qmd              # manuscript (reads outputs/ only, never computes)
├── analysis.qmd           # all data processing & statistical analysis
├── research_proposal.md   # background, RQs, methods, timeline (living doc)
├── data/
│   ├── raw/                # FILL IN once pulled — never edit or delete these files
│   └── derived/             # cleaned/derived data written by analysis.qmd
├── outputs/
│   ├── figures/              # figures written by analysis.qmd, read by index.qmd
│   └── tables/                # tables written by analysis.qmd, read by index.qmd
├── references/
│   ├── references.bib        # bibliography (several entries still marked FILL IN)
│   └── nature.csl            # citation style; swap this file to retarget a journal
└── renv.lock               # FILL IN — generated by `renv::snapshot()` once packages are added
```

**Rule:** nothing in `data/raw/` is ever modified in place. All filtering,
cleaning, and computation happens in `analysis.qmd` and is written to
`data/derived/` or `outputs/`.
